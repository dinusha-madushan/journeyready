# Background Image Setup

## Required File
Save the Sri Lanka landscape image as: `public/bg.jpg`

The image should show:
- Sigiriya Rock on the left
- Nine Arch Bridge with train
- White Buddhist stupa (temple)
- Beach with palm trees on the right
- Mountains in the background
- Blue sky with clouds

## Image Specifications
- **Filename**: `bg.jpg`
- **Location**: `public/bg.jpg`
- **Recommended size**: 1920x1080 or larger
- **Format**: JPEG (optimized for web)
- **Quality**: 80-90% (balance between quality and file size)

## Current Status
The CSS is already configured to use `/bg.jpg` as the background image.
Once you save the image to `public/bg.jpg`, it will automatically appear as the background.

## Fallback
If the image is not present, the app will show a solid color background instead.
