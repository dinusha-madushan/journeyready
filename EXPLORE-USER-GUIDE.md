### Step 1: Select a Province

**Click any province on the map:**
- **Western** (Turquoise) - Colombo, beaches
- **Central** (Burgundy) - Kandy, tea country
- **Southern** (Green) - Galle, coastal areas
- **Northern** (Orange) - Jaffna, culture
- **Eastern** (Purple) - Trincomalee, surfing

### Search & Filter

**Search Bar:**
- Type place name: "temple", "waterfall", "beach"
- Searches names and descriptions
- Results update instantly

**Category Filter:**
- All (default)
- Beach 🏖️
- Hills ⛰️
- History 🏛️
- Wildlife 🐘
- City 🏙️
- Cultural 🛕

### Navigation Options

**Breadcrumb Navigation:**
- Click **"Sri Lanka Map"** → Return to interactive map
- Click **"Provinces"** → View all provinces list
- Click **Province name** → View districts in that province
- **Current location** is highlighted in orange

**Place Cards:**
- **Get Route** → Plan journey to this place
- **⭐ Save** → Add to favorites

## 🎯 Quick Tips

### Finding Specific Places

**Want to find beaches?**
1. Click **Southern** province
2. Select **Galle** or **Matara** district
3. Filter by **Beach** category

**Want to visit temples?**
1. Click **Central** province
2. Select **Kandy** district
3. Filter by **Cultural** category
4. Search "temple"

**Want to see waterfalls?**
1. Click **Uva** province
2. Select **Badulla** district
3. Search "falls"

### Planning a Route

**From any place card:**
1. Click **"Get Route"**
2. Opens Routes page with destination pre-filled
3. Enter your starting point
4. Get directions

### Mobile Usage

**On mobile devices:**
- Tap provinces on map
- Swipe through district cards
- Use search for quick access
- All features fully functional
